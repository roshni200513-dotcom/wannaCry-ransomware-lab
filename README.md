# WannaCry Ransomware Lab

## Overview
This project demonstrates the analysis of the WannaCry ransomware attack chain in a controlled VirtualBox laboratory environment.

## Tools Used
- Kali Linux
- VirtualBox
- Nmap
- Metasploit Framework
- Windows 7

## Learning Outcomes
- Network Scanning
- Vulnerability Assessment
- MS17-010 Analysis
- Metasploit Usage
- Ransomware Behavior Analysis

## Disclaimer
This project was conducted in an isolated lab environment for educational purposes only.
